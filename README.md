This is a simple UI code for the Kabadiwala Connect App/Website. For running this code you first need 
to first install flet in the directory that you download the code to.
To download flet, go to the terminal at the directory and use the code: 
"python -m pip install flet".
You can run the file after installation of flet with:
"python kabadiwala_connect_ui.py"
